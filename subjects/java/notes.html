  • JVM: اختصار Java Virtual Machine، مترجم (Interpreter) خاص لتشغيل الـ Byte Code.

مكونات for: التهيئة (Initialization) مرة واحدة، ثم الشرط (Condition) قبل كل دورة، ثم التغيير (Update) بعد كل دورة.

for لما يكون عدد التكرارات معروفاً.

الخاصيةwhiledo..while
فحص الشرطقبل التنفيذبعد التنفيذ
التنفيذ الأولقد لا يحدثيحدث دائماً مرة واحدة على الأقل
  • break: خروج فوري من الحلقة. مثال: لو i == 5 break ← يطبع 1 2 3 4.
  • continue: يتخطى الدورة الحالية فقط. مثال: لو i % 3 == 0 continue من 1 إلى 7 ← يطبع 1 2 4 5 7.

الدوال (Methods)معمل 10

الدالة جزء من الكود ينفذ مهمة محددة وله اسم، نستدعيه أكثر من مرة بدون تكرار الكتابة. فوائدها: تقليل التكرار، وتنظيم البرنامج، وسهولة الصيانة، وإعادة الاستخدام.

النوعمثال
لا ترجع قيمة ولا تأخذ معاملاتstatic void sayHello()
لا ترجع قيمة وتأخذ معاملاتstatic void printAdd(int total)
ترجع قيمة ولا تأخذ معاملاتstatic int getNumber() { return 10; }
ترجع قيمة وتأخذ معاملات (الأكثر استخداماً)static int add(int a, int b) { return a + b; }

void تعني أن الدالة لا ترجع شيئاً، والدالة اللي ترجع قيمة لازم فيها return.

الدالةالوظيفةمثال
