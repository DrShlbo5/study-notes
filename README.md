# مذكرة مراجعة الاختبارات

موقع مراجعة للطلاب على GitHub Pages: لكل مادة تبويب فيه ملخص، أسئلة نظري، صح وخطأ، مسائل للحل، واختبار قصير.

**إضافة مادة = إضافة مجلد.** ما تحتاج تعدّل أي كود. ترفع مجلد المادة داخل `subjects/` والموقع يضيف التبويب لحاله بعد دقيقة أو دقيقتين.

---

## هيكل المشروع

```
index.html              صفحة الموقع (ثابتة، لا تعدّلها لإضافة مادة)
site.json               عنوان الموقع والوصف والتذييل
assets/style.css        التصميم
assets/app.js           يقرأ المواد ويعرضها
scripts/build.mjs       يبني subjects.json ويتحقق من صحة الملفات
.github/workflows/      ينشر الموقع تلقائياً عند كل رفع
subjects/
  _template/            قالب جاهز: انسخه لمادة جديدة (المجلدات اللي تبدأ بـ _ ما تظهر)
  java/
  sql/
  php/
```

## ملفات المادة

كل مادة مجلد في `subjects/<id>/`. اسم المجلد `id` حروف إنجليزية صغيرة وأرقام و `-` فقط (مثل `networks` أو `math-101`).

| الملف | إجباري؟ | وش فيه |
|---|---|---|
| `info.json` | نعم | `title` اسم التبويب، `short` اسم مختصر لعنوان الاختبار، `color` و`colorDark` لون المادة، `order` ترتيب التبويب، `sources` أسماء ملفات المراجع اللي انضافت |
| `notes.html` | لا | الملخص: جزء HTML فقط (بدون `html` أو `head` أو `body` أو `script`) |
| `theory.json` | لا | أسئلة مقالية: `[{"q": "السؤال", "a": ["نقطة", "نقطة"]}]` |
| `truefalse.json` | لا | صح أو خطأ: `[{"s": "العبارة", "t": true, "w": "الشرح"}]` |
| `problems.json` | لا | مسائل للحل: `{"title", "intro", "codePlaceholder", "tags": {"key": "اسم"}, "items": [{"t", "lvl", "tags", "q", "h", "s"}]}` |
| `quiz.json` | لا | اختيار من متعدد: `[{"q": "السؤال", "code": "كود اختياري", "o": ["خيار", ...], "a": 0, "w": "الشرح"}]`، و`a` رقم الخيار الصحيح ويبدأ من 0 |

الترتيب داخل التبويب: الملخص، ثم أسئلة النظري، ثم صح أو خطأ، ثم المسائل، ثم الاختبار. والفهرس أعلى التبويب يتولّد تلقائياً من كل `<h2>`.

### كتابة notes.html

- كل درس يبدأ بـ `<h2 id="...">`. خلّ الـ id يبدأ بحرف من المادة عشان ما يتكرر بين المواد (مثل `n1`، `n2` للشبكات).
- رقم المحاضرة أو المعمل: `<span class="lab">محاضرة 2</span>` داخل الـ h2.
- المعلومة المهمة: `<mark>...</mark>`.
- تنبيه: `<div class="trap"><b>انتبه</b>النص</div>`.
- كود: `<pre><code>...</code></pre>`، واكتب `&lt;` بدل `<` داخل الكود.
- جدول: `<div class="tbl"><table>...</table></div>`.
- عمودين: `<div class="grid2"><div>...</div><div>...</div></div>`.
- حل طويل يختفي: `<details><summary>العنوان</summary>...</details>`.

## إضافة مادة جديدة

### من موقع GitHub (بدون برامج)

1. افتح المستودع، ثم مجلد `subjects`.
2. **Add file ← Upload files**، واسحب مجلد المادة كامل (مثلاً `networks/` فيه `info.json` و`notes.html`...).
3. **Commit changes**. بعد دقيقة أو دقيقتين يظهر التبويب.

لو فيه خطأ في ملف (JSON ناقص فاصلة مثلاً)، النشر يفشل ويظهر السبب بالعربي في تبويب **Actions**، والموقع يبقى على آخر نسخة سليمة.

### بالذكاء الاصطناعي (Claude أو ChatGPT أو غيرهم)

ارفع ملفات المادة (PDF وغيرها) وقل له:

> اقرأ README.md في المستودع، وأضف هذي المادة في `subjects/` بنفس الهيكل.

وتعليمات الـ AI موجودة تحت.

## تعليمات للذكاء الاصطناعي (AI agents)

لما يطلب منك المستخدم تضيف مادة أو مراجع جديدة:

1. **اقرأ المراجع كاملة.** إذا كان النص المستخرج من PDF قليلاً (شرائح صور)، حوّل الصفحات لصور واقرأها.
2. **حدد المادة:** إذا المرجع لمادة موجودة (شوف `sources` و`title` في كل `info.json`)، أضف للمجلد نفسه. وإذا لمادة جديدة، انسخ `subjects/_template/` لمجلد جديد.
3. **لا تكرر:** قبل ما تضيف، ابحث في ملفات المادة (`notes.html` و`*.json`) عن الموضوع. أضف فقط الناقص، وفي المكان المناسب (نفس الـ h2 لنفس الدرس).
4. **غطِّ كل شيء:**
   - كل تعريف أو فرق أو تعداد في المحاضرات يصير سؤالاً في `theory.json`.
   - كل تمرين في المعامل له حل: في `notes.html` (قسم الحلول) أو في `problems.json`.
   - أسئلة الاختبار في `quiz.json`: ركّز على "وش يطبع الكود" والأخطاء الشائعة.
   - المعلومات اللي تحتمل صح وخطأ في `truefalse.json`.
5. **سجّل المراجع:** أضف اسم كل ملف استخدمته إلى `sources` في `info.json`.
6. **الأسلوب:** عربي بسيط بلهجة خفيفة مثل الموجود. المصطلحات التقنية والكود بالإنجليزي.
7. **تحقق:** شغّل `node scripts/build.mjs`، ولازم يطلع بدون أخطاء. وتأكد إن `a` في quiz.json يشير للخيار الصحيح فعلاً.
8. لا تعدّل `index.html` ولا `assets/` ولا `scripts/` لإضافة محتوى.

## التشغيل على جهازك

```bash
node scripts/build.mjs
python -m http.server 8000
```

ثم افتح `http://localhost:8000`. (فتح `index.html` مباشرة بدون سيرفر ما يشتغل لأن المتصفح يمنع قراءة الملفات.)

## النشر أول مرة على GitHub Pages

1. أنشئ مستودع جديد في GitHub وارفع كل محتويات هذا المجلد للفرع `main`.
2. **Settings ← Pages ← Build and deployment ← Source: GitHub Actions**.
3. انتظر انتهاء أول نشر في تبويب **Actions**. الرابط يكون `https://<اسمك>.github.io/<اسم-المستودع>/`.
